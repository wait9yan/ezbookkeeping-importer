# 前端规范适用范围

项目首期为 Python 后台服务和单次 CLI，无独立前端。以下规范均为不适用，无待填充的前端开发工作。终端文本展示属于[后端与 CLI](../backend/index.md)，不能据此假设存在网页、组件或前端状态库。

| 规范 | 当前状态 |

| [前端目录结构](directory-structure.md) | 不适用 |
| [前端组件规范](component-guidelines.md) | 不适用 |
| [前端 Hook 规范](hook-guidelines.md) | 不适用 |
| [前端状态管理](state-management.md) | 不适用 |
| [前端质量验证](quality-guidelines.md) | 不适用 |
| [前端类型安全](type-safety.md) | 不适用 |

后续实际新增前端时，再根据代码建立规范。所有新增或更新的 Trellis 文档使用简体中文。
